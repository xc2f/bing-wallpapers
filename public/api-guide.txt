Bing Wallpapers Archive API

GET /api/waterfall?locale=en&q=title%3Alake&page=1

Use this read-only endpoint to search and browse the wallpaper archive. It
returns JSON and requires no authentication. The locale parameter is required
and accepts en, zh, es, fr, de, ja, or ko. A missing or unsupported locale
returns HTTP 400.

The optional q parameter accepts phrases, fields such as title:lake or
desc:turtle, and date expressions such as date:2024-01-01..2024-01-31.
Use uppercase AND, OR, and NOT with parentheses to combine conditions.
URL-encode the search expression. Malformed expressions yield no matches.

The year (YYYY), month (MM), category, tag, and country filters intersect
with q and with one another. GET /api/filters?locale=zh returns the valid IDs,
localized names, and distinct image counts in categories, tags, and
countries. Pass an ID to the corresponding filter parameter.

The response contains items, page, totalCount, and totalPages. Page numbers
start at 1. Request page + 1 with the same filters while page < totalPages.
An empty result has items=[] and totalPages=1. Each item includes a title,
description, localized archive date, detailHref, and detailApiHref. Resolve
both paths against the site origin. Image URLs are empty when unavailable.

GET /api/wallpapers/zh/20261029 returns JSON detail for that wallpaper.
It provides the title, description, archive date, copyright, source page,
and image URLs. headline, quickFact, bingUrl, and location are included when
available. Each location point has latitude, longitude, and a label.
Location precision is exact for Bing coordinates and country for
representative country or region points. Only exact locations include mapUrl.
Unsupported locales return HTTP 400. Unknown wallpaper IDs return HTTP 404.
Aliases redirect to the canonical ID with HTTP 308.

The wallpaper detail URL also supports Accept: text/markdown. Append /text
to a localized detail URL to request UTF-8 plain text. These formats also
include the available headline, quick fact, location, and Bing link.
