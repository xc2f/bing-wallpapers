# Bing Wallpapers 设计风格

在本仓库进行 UI 工作时，先阅读 [设计风格文档](../../docs/design-style.md)，再读取本次任务对应的组件和 `app/globals.css`。文档数值是当前实现的快照，冲突时核对源码；用户明确提出的改版要求优先，并同步更新受到影响的约定。

保留摄影优先的层级：衬线展示标题、无衬线正文、炭黑/暖象牙双主题、克制的琥珀强调色与柔和分隔。复用现有组件和语义 token。

实施时关注本项目容易误改的边界：

- 全局 CSS 会重映射部分 Tailwind `stone`、`white`、`amber` 类，某些声明含 `!important`。不能仅凭类名判断最终颜色。
- 强调文字、实底按钮、染色表面和焦点环使用不同 token，尤其浅色主题下不能混用。
- 图片列表和幻灯片允许 `object-cover`；详情主图保留完整比例。照片上白字与黑底幻灯片有独立颜色语义。
- 画廊包含四档信息、两种布局、三档外观和宽屏偏好；不要因局部调整覆盖这些选择。
- 639px 及以下的共用弹层通过 `ResponsivePanel` 变为底部模态抽屉，保留安全区、滚动与关闭后的焦点返回。
- 详情环境光在窄屏或粗指针设备上减少模糊与合成层；新增效果沿用现有减少动态效果策略。

按改动范围验证深浅主题、窄屏/桌面、长文本和交互状态。涉及画廊、弹层或动效时，再检查各自受影响的模式。记录实际验证结果；未运行浏览器检查时明确说明，不将源码检查表述为视觉验收。
